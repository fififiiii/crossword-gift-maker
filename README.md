# Crossword Layout Lab

一个用来制作私人填字游戏（Crossword）的浏览器小工具。

输入一组「答案 + 提示」，自动生成尽可能紧凑、交叉尽可能多、接近正方形的 Crossword，并排版成适合打印的 A4 页面，最后可以导出 PNG 或 PDF。

这个工具最初是为了给朋友制作一份生日礼物：把一起去过的地方、共同爱好、旅行经历、食物、音乐、生活习惯和只有彼此知道的梗，变成一道道 Crossword 线索。

## 功能

- 批量粘贴「答案 + 提示」
- 手动添加、修改和删除词条
- 自动生成相互连接的 Crossword
- 尽可能增加单词之间的交叉
- 尽可能压缩整体面积
- 优先生成接近正方形的版式
- 对当前词库重新生成不同布局
- 可以多次尝试并自动选择更紧凑的版本
- A4 页面实时预览
- 自动生成 Across / Down 编号和提示
- 显示 / 隐藏答案
- 导出 PNG
- 导出 PDF
- 完全在浏览器中运行，无需安装

## 输入格式

每行输入一组：

`答案 提示`

例如：

```text
ROADTRIP 一起出发后总会发生故事的旅行方式
SUNRISE 为了它，我们愿意偶尔早起
COFFEE 一场聊天最常见的开场
MUSEUM 下雨天也愿意去逛很久的地方
CONCERT 听到熟悉前奏就会互相看一眼的现场
```

答案会自动转换为大写字母。

如果答案由多个英文单词组成，直接连写，不需要空格：

```text
BUSINESSCLASS 如果要在飞机上过夜，会想选的位置
HAPPYBIRTHDAY 今天这张字谜存在的理由
```

## 使用方法

1. 在输入框中粘贴「答案 + 提示」，也可以逐条添加和修改。
2. 将输入内容加入当前词库，或者直接替换全部内容。
3. 点击「重新生成」，生成一版新的 Crossword。
4. 如果觉得版式太长、太散或不够平衡，可以再次生成。
5. 也可以让程序多尝试几次，自动选择更紧凑的布局。
6. 在 A4 页面中预览最终效果。
7. 根据需要显示或隐藏答案。
8. 导出 PNG 或 PDF。

## 做一张属于某个人的 Crossword

这里的 Clue 不一定要像传统填字游戏一样，是严格的词典释义或知识问答。

如果它是一份送给朋友的礼物，提示也可以是一段共同回忆。

例如：

```text
MEXICO 你的精神故乡
ROADTRIP 四川、贵州、西藏、广西、云南旅行的共同点
RACECAR 只闻其声，未见其车
SLEEP 每天最重要的事情
```

解题的过程不只是「猜出正确的单词」，也包括：

**想起来为什么答案会是这个词。**

所以你可以把很多属于一个人的小事放进去：

- 一起去过的地方
- 旅行经历
- 共同爱好
- 食物
- 音乐
- 电影
- 运动
- 一个人比另一个人更擅长的事情
- 奇怪的小习惯
- 只有彼此知道的梗
- 曾经一起做过的事
- 想一起尝试的新活动
- 未来想去的地方
- 很小、但一直记得的瞬间

最后得到的 Crossword，也可以看成一张由很多关键词组成的「人物档案」。

## Crossword 生成逻辑

程序会尝试不同的单词位置，并优先考虑：

1. **更多交叉**  
   尽可能让不同答案共享字母，而不是形成彼此孤立的单词。

2. **更紧凑**  
   减少 Crossword 占据的整体面积。

3. **更接近正方形**  
   避免出现特别狭长的版式，让最终结果更适合页面排版。

Crossword 的生成具有一定随机性。

因此，同一组答案可以生成不同的布局。

如果不喜欢当前结果，可以重新生成，直到找到满意的一版。

## A4 排版

最终页面按照 A4 礼物 / 打印版本设计，包括：

- Crossword 标题
- Crossword 方格
- 自动编号
- Across 提示
- Down 提示

完成后可以直接导出：

- PNG
- PDF

可以继续在 Illustrator、Photoshop 或其他设计软件中进行二次排版，也可以直接打印。

## 隐私

Crossword Layout Lab 完全在浏览器本地运行。

输入的答案、私人回忆和 Clue 不需要上传到服务器。

因此也适合用来制作包含私人经历、共同回忆和 inside jokes 的 Crossword。

## 本地运行

这个项目不需要安装依赖，也没有构建过程。

下载项目后，直接用现代浏览器打开：

```text
index.html
```

即可使用。

## GitHub Pages

这是一个纯前端项目，可以直接通过 GitHub Pages 发布成网页。

上传项目后：

1. 打开仓库的 `Settings`
2. 进入 `Pages`
3. 在 `Build and deployment` 中选择 `Deploy from a branch`
4. 选择 `main` 分支
5. 文件夹选择 `/ (root)`
6. 点击保存

稍等片刻，就可以通过 GitHub Pages 地址直接访问 Crossword 生成器。

## 为什么做这个工具

最开始，我只是想给朋友做一张生日 Crossword。

答案并不是知识问答，而是关于一个人的很多碎片：

去过的地方、喜欢的东西、生活习惯、共同旅行、兴趣、食物、玩笑，以及一些只有彼此才知道为什么会出现在这里的词。

在制作过程中，我发现现有的 Crossword 工具虽然可以帮忙排列单词，但我还希望对最终的视觉结果有更多控制：

**让单词尽可能多地交叉，让整个字谜尽可能紧凑，让它接近正方形，并且可以直接变成一张干净的 A4 礼物。**

于是有了这个小工具。
